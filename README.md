A one-line patch note for a bug in real life — human biology, in the
terse register of a real release note. v2.4.1: the body requests a
software update (sleep) every night and ignores the "remind me later"
button.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when the variable is unset). No network, no
randomness: every run writes the same bytes.
